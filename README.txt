СЛУШАЮ — PWA аудиоплеер

Файлы для публикации:
- index.html
- manifest.webmanifest
- sw.js
- icons/

GitHub Pages:
1. Создай новый публичный репозиторий, например audiobook-player.
2. Загрузи ВСЁ содержимое этой папки в корень репозитория.
3. Settings → Pages → Deploy from a branch → main / root → Save.
4. Открой полученный HTTPS-адрес в Safari на iPhone.
5. Поделиться → На экран «Домой».

Важно:
- PWA и service worker работают через HTTPS (GitHub Pages подходит).
- Позиция книг и библиотека сохраняются в localStorage конкретного браузера/PWA.
- Приложение кэширует свой интерфейс, но не аудиокниги целиком.
- knigi-audio.ru может блокировать автоматические запросы или менять формат плеера. В коде уже есть несколько способов извлечения аудио, но для скрытого API сайта может понадобиться отдельный адаптер.
- Эквалайзер синхронизирован с состоянием воспроизведения. Для same-origin аудио используется Web Audio spectrum; для внешних аудиофайлов включается безопасная анимация, чтобы не ломать воспроизведение из-за CORS.
